# ATmega32 Digital Door Lock

## Project Overview

A password-based digital door lock system developed using the ATmega32 microcontroller and Embedded C.

The system uses a keypad for password entry, an LCD for user feedback, and a servo motor to control the door lock mechanism.

The project is developed using Microchip Studio and simulated using Proteus.

## Features

* Password entry using a matrix keypad.
* Password verification.
* LCD interface for displaying system messages.
* Servo motor control for locking and unlocking the door.
* LED status indication.
* Buzzer feedback for system events.
* Modular driver-based software architecture.

*Note: Features are being implemented and tested as part of the project development.*

## Hardware Components

* ATmega32 Microcontroller
* 4×3 Matrix Keypad
* 16×2 LCD
* Servo Motor
* LED
* Buzzer

## Software and Tools

* Embedded C
* Microchip Studio
* Proteus Design Suite

## Project Structure

The project is organized into separate drivers and application-level code to improve readability, modularity, and maintainability.

## Simulation

The circuit is designed and tested using Proteus simulation.

The simulation files will be included in this repository.

## Learning Objectives

* Interfacing a matrix keypad with a microcontroller.
* Implementing password verification logic.
* Interfacing an LCD.
* Generating PWM signals using Timer1.
* Controlling a servo motor.
* Developing modular Embedded C drivers.
